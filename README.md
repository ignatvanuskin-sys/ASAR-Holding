# ASAR HOLDING — корпоративный сайт

Премиальный корпоративный сайт строительной компании **ASAR HOLDING** (Кокшетау, Казахстан).
Стек: **Next.js 15 (App Router) · TypeScript · Tailwind CSS 4 · Framer Motion**.

---

## 1. Быстрый старт

```bash
npm install
npm run dev      # http://localhost:4173
npm run build
npm run start    # production, http://localhost:4173
npm run images   # пересобрать изображения из _assets/raw
```

Сборка: 15 страниц, полностью статический рендеринг (кроме `POST /api/lead`).

## 3. Структура проекта

```
app/

  page.tsx                главная
  about/                  о компании
  projects/               список объектов
  projects/[slug]/        страница объекта (SSG, 4 объекта)

  api/lead/route.ts       приём заявок с формы
  sitemap.ts, robots.ts, icon.svg, not-found.tsx

  Header, Hero, StatsBar, About, Directions, Projects, ProjectCard,

  PageHero, SectionHeading, Reveal, Wordmark, Footer
lib/site.ts               все данные сайта
scripts/
  fetch-images.mjs        загрузка исходников из открытых публикаций
  optimize-images.mjs     кроп рекламных наложений + сжатие + og.jpg и иконки
public/images/            16 оптимизированных фотографий объектов
```

### Дизайн-система

Палитра выведена из реальных материалов бренда (вывеска офиса, входная группа
ЖК ASAR PREMIUM, логотип): глубокий графит `#0E1113`, тёплый белый `#F5F2EC`,
бетонно-серый, фирменный зелёный `#1B5E52` и приглушённая бронза `#A8875A`.

Типографика — двухшрифтовая пара: **Manrope** (интерфейс и текст) + **Playfair Display**
(акцентные врезки курсивом). Токены заданы в `app/globals.css` через `@theme`.

## 4. Форма заявки

`components/LeadForm.tsx` отправляет `POST /api/lead` с телом
`{ name, phone, comment, company }` (поле `company` — honeypot для ботов).

Обработчик в `app/api/lead/route.ts` уже валидирует данные и возвращает
`{ ok: true }`. Чтобы подключить CRM, почту или Telegram, допишите доставку
в блоке `// ── Куда отправлять ──` — менять разметку формы не требуется.

## 5. Производительность и доступность

- `next/image` для всех фотографий: AVIF/WebP, responsive `sizes`, lazy loading ниже фолда,
  `priority` только на первом экране;
- анимации — только `transform`/`opacity`, полностью отключаются при `prefers-reduced-motion`;
- семантическая разметка, один `h1` на страницу, `alt` у всех изображений,
  `aria-label` у иконочных кнопок, skip-link, видимый `focus-visible`, поддержка клавиатуры
  в меню и лайтбоксе (Esc, стрелки);
- затемняющие оверлеи рассчитаны так, чтобы текст на фотографиях сохранял контраст WCAG AA.

## 6. Что заменить при деплое

1. `site.url` в `lib/site.ts` — сейчас указан домен-заглушка `https://asar-holding.kz`
   (используется для `metadataBase`, `sitemap.xml`, `robots.txt` и Open Graph).
2. `public/og.jpg` — при необходимости пересобрать под финальный брендинг.
3. Часы работы: в источниках подтверждено только время открытия (09:00), поэтому
   подвал сайта честно ссылается на 2ГИС. После уточнения графика — обновить
   `contact.hoursNote` в `lib/site.ts`.
4. Логотип: сейчас используется наборный знак (текстовый wordmark). Если появится
   официальный векторный логотип — заменить компонент `components/Wordmark.tsx`.
